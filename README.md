## 1. 조립

손, 서보, 확장 보드는 조립된 상태로 옵니다. 직접 할 일은 4단계입니다.

1. **받침 다리 4개**: 나일론 기둥(M4×6, 양쪽 암나사)을 받침판 아래에 대고 위에서 M4×6 나사로 조입니다. 나일론이라 너무 세게 조이지 마세요.
2. **초음파 센서**: 받침판 앞면 구멍에 기둥(M4×6+6, 한쪽 수나사) 2개를 넣고 안쪽에서 M4 너트로 고정합니다. 센서를 기둥에 대고 M4×6 나사 2개로 조입니다. 4핀 케이블로 확장 보드의 **I2C 단자**에 연결합니다.
3. **micro:bit**: LED와 A·B 버튼이 바깥을 보게 해서 슬롯에 끝까지 꽂습니다. 우리 보드는 **micro:bit V2**입니다(금색 터치 로고가 있음).
4. **전원**: 스위치 OFF 상태에서 동봉된 어댑터(7.4V 3A, DC 3.5)를 꽂고 ON으로 켭니다. USB만으로는 서보가 움직이지 않습니다.

### 확장 보드 단자

보드에 인쇄된 단자 번호 기준입니다.

| 인쇄 번호 | 기능 | 쓰임 |
|---|---|---|
| 4 | I2C | **초음파 센서 연결함** ✅ |
| 5 | 시리얼 | — |
| 6 | I2C | 다른 I2C 장치(AI 카메라 등) |

> 4번에 꽂은 센서는 5.2 예제로 동작을 확인했습니다. 5번과 6번의 기능은 공식 기능도(2.2.3)와 보드 사진을 비교해서 추정한 것입니다.

### 같이 들어 있는 건전지 케이스

AAA 2개짜리 micro:bit 전용 케이스는 **micro:bit만 따로** 켤 때 씁니다. AiHand는 어댑터 → 확장 보드 → micro:bit 순서로 전원을 받기 때문에 필요 없습니다.

## 2. 서보 번호와 각도

| 서보 | 부위 | 굽힘(주먹) | 폄(손바닥) |
|---|---|---|---|
| 1 | 엄지 | 130° | 50° |
| 2~5 | 검지 ~ 새끼 | 50° | 130° |
| 6 | 손목 회전 받침 | — | — |

- 90°는 반쯤 쥔 상태(초기 자세)입니다.
- 엄지는 반대 방향으로 달려 있어서 **엄지 각도 = 180 − 다른 손가락 각도**입니다.
- 지문자 각도표는 이 표를 기준으로 만듭니다.

## 3. 프로그램 넣기

### 준비 (처음 한 번만)
- 편집기: https://makecode.microbit.org (설치할 필요 없음)
- 드라이버: 공식 문서 부록의 `ch341ser.exe`
- 확장 블록: MakeCode **Extensions**에서 `https://github.com/Hiwonder/StartbitV2` 추가 (micro:bit V2용)

### 넣는 방법
- **A. 끌어다 놓기**: USB를 연결하면 생기는 `MICROBIT` 드라이브에 `.hex` 파일을 끌어다 놓습니다. 노란 LED 깜빡임이 끝나면 완료입니다.
- **B. MakeCode**: **Import → Import file**로 파일을 연 뒤 **Download**를 누릅니다. 처음이라면 **Connect Device → Pair**부터 합니다.

LED가 깜빡이는 동안에는 케이블을 건드리지 마세요.

## 4. 예제

예제 파일(5장, `.hex` 6개)은 공식 위키에서 받습니다.
https://wiki.hiwonder.com/projects/AiHand/en/latest/_static/source_code/aihand_basic_games_lesson.zip

### 5.1 버튼 제어 — `02 Button Control Program.hex` ✅

| 입력 | 동작 |
|---|---|
| 전원 켬 | 반쯤 쥔 자세 (서보 1~6 = 90°) |
| A 버튼 | 주먹 (엄지 130°, 나머지 50°) |
| B 버튼 | 손바닥 (엄지 50°, 나머지 130°) |
| 로고 터치 | 반쯤 쥔 자세 |

### 5.2 초음파 거리 — `02 Ultrasonic Ranging Program.hex` ✅

| 센서와의 거리 | 동작 |
|---|---|
| 5cm 이하 | 주먹 |
| 5~25cm | 가까울수록 쥐고 멀수록 폄 |
| 25cm 이상 | 손바닥 |

동작 원리: 거리(mm) ÷ 10 → 5~25cm 범위로 제한 → `map`으로 각도 50~130 변환 → 서보 2~5 = 각도, 엄지 = 180 − 각도.

이 거리 블록은 요구사항 **S-08(사람이 너무 가까우면 동작 멈춤)**에 그대로 쓸 수 있습니다.

### 남은 예제
- 5.3 초음파로 공 잡기
- 5.4 소리로 손가락 세기
- 5.5 공 잡고 박수로 놓기
- 5.6 앱 제어 (블루투스) — 앱 이름과 링크는 문서에 없어서 따로 찾아야 함

## 5. 끄기와 보관

1. 전원 스위치 **OFF** → 서보가 그 자리에서 멈춥니다.
2. 어댑터를 콘센트에서 뽑고 USB를 뺍니다.

- 프로그램은 micro:bit에 남아 있어서 **다음에 켜면 바로 다시 실행**됩니다. 켜기 전에 손 주변을 비워 두세요.
- 켜자마자 움직이지 않게 하려면 5.1 예제를 넣어 두세요.
- 주먹을 꽉 쥔 상태로 오래 두지 마세요.
- AiHand는 **12/21에 반납**합니다. 원상복구가 가능한 변형만 하세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 손가락이 전혀 안 움직임 | 어댑터 연결, 스위치 ON (USB 전원만으로는 안 됨) |
| 일부 손가락만 이상하게 움직임 | 서보 케이블이 빠졌거나 순서가 바뀜. 처음 꽂혀 있던 그대로 둘 것 |
| `MICROBIT` 드라이브가 안 보임 | 충전 전용 USB 케이블일 수 있음. 다른 케이블로 바꿔 보기 |
| 초음파 반응 없음 | 전원을 끄고 6번(I2C)으로 옮겨 보기, 커넥터 끝까지 꽂기 |
| 서보가 "지잉" 소리를 냄 | 끝까지 가서 힘을 받는 중. 바로 손을 펴거나 초기 자세로 |
