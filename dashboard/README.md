# Sign Bridge 웹 대시보드 (역할 4)

AI Hand 5대를 중앙에서 관제하고, 지문자 표현과 학습 과정을 실시간으로 보여 주는 웹 대시보드입니다.
지금은 **가짜 데이터**로 동작합니다. 중앙 PC(FastAPI)가 아래 메시지 형식으로 WebSocket을 열면 그대로 진짜 데이터로 바뀝니다.

## 실행

```bash
cd dashboard
npm install
npm run dev        # http://localhost:5173
npm test           # 자모 분해·통계 계산 테스트
npm run build      # dist/ 에 배포용 파일
```

진짜 서버에 연결할 때는 주소 뒤에 `?ws=` 를 붙입니다: `http://localhost:5173/?ws=ws://PC주소:8765#/`
사이드바 아래 표시가 `가짜 데이터` → `PC 연결됨`으로 바뀝니다.

- 음성 입력은 크롬에서만 되고 인터넷이 필요합니다.
- 카메라와 마이크는 `localhost`나 `https`에서만 권한을 받을 수 있습니다.
- Tailwind는 v3(PostCSS)을 씁니다. v4의 네이티브 스캐너는 이 PC의 Windows 앱 제어 정책에 막혀서 스타일이 생성되지 않았습니다.

## 화면 (기획안 번호)

| 화면 | 주소 | 내용 |
|---|---|---|
| ① 통합 관제 | `#/` | 손 5대 연결·방향·역할·상태(대기/실행/완료/오류), 지금 손과 글자, 전체 진행률, 다음 손, 시스템 시작/정지 |
| ② 지문자 표현 | `#/express` | 텍스트·음성 입력, 자모 분해와 담당 손 미리보기, 지금 글자 강조, 다음 글자, 표현 불가 글자는 화면 그림, 시작/일시정지/재개/중지 |
| ③ 학습 | `#/learn` | 글자 선택 → 시범 → 웹캠 → 정답/오답·정확도, 오답이면 시범 다시, 정답이면 칭찬 동작, 연속 정답·진행률 |
| ④ 개별 제어 | `#/robots` | 손별 연결·상태, 손가락 목표 각도, 테스트 전송과 결과, 오류 해제, 긴급 정지 |
| ⑤ 통계 | `#/analytics` | 표현 횟수, 인식률(N-02), 피드백 시간(N-03), 음성 정확도(N-04), 학습 성공률(S-09), 오류, 날짜별 그래프, 글자별 정답률, 전체 기록 |
| ⑥ 설정 | `#/settings` | 손 방향·역할, 자모별 담당 손·손가락 각도·표현 불가, 동작 속도, 카메라·음성, JSON 내보내기/불러오기 |

긴급 정지는 모든 화면의 사이드바(휴대폰에서는 위쪽)에 있습니다.

## 메시지 형식 (WebSocket, JSON)

### 대시보드 → 중앙 PC
| 메시지 | 언제 |
|---|---|
| `{"type":"express","word":"사랑","plan":[{"jamo":"ㅅ","hand":1,"angles":[90,90,90,90,90]},…],"stepMs":1200,"gapMs":250}` | 표현 시작. `hand:null`이면 화면 그림으로 대체하는 글자 |
| `{"type":"demo","jamo":"ㄱ","hand":1,"angles":[…]}` | 학습 시범 |
| `{"type":"recognize","jamo":"ㄱ"}` | 사용자 손 인식 시작 (인식 AI에 전달) |
| `{"type":"pause"}` / `{"type":"resume"}` / `{"type":"stop"}` | 일시정지 / 재개 / 중지 |
| `{"type":"estop"}` | 긴급 정지 |
| `{"type":"test","hand":3,"jamo":"ㄱ","angles":[…]}` | 개별 손 테스트 |
| `{"type":"praise","hand":1}` | 칭찬 동작 |
| `{"type":"system","on":true}` | 시스템 시작/정지 |

### 중앙 PC → 대시보드
| 메시지 | 뜻 |
|---|---|
| `{"type":"hand_status","hand":1,"connected":true}` | 손 연결 상태 (접속 직후 5대 모두 보내 주세요) |
| `{"type":"step","i":0,"jamo":"ㅅ","hand":1,"state":"start"}` | i번째 자모 동작 시작 (`state:"end"`는 끝) |
| `{"type":"done","ms":6800}` | 단어(또는 시범) 전체 끝 |
| `{"type":"paused"}` / `{"type":"resumed"}` / `{"type":"stopped","estop":false}` | 상태 변경 확인 |
| `{"type":"test_result","hand":3,"jamo":"ㄱ","ok":true,"ms":950}` | 테스트 결과 |
| `{"type":"error","hand":2,"msg":"통신 끊김"}` | 손 오류 (알림 표시) |
| `{"type":"recog","jamo":"ㄱ","prob":0.92,"ms":420}` | 인식 AI 결과: 인식 글자, 확신도, 반응 시간 |

## 나중에 할 것
- 손가락 각도는 임시값(전부 90°)입니다. 역할 2 각도표가 나오면 설정 화면에서 고치거나 JSON으로 불러옵니다.
- 지문자 그림 파일은 자리만 있습니다.
- 기록·설정은 브라우저(localStorage)에만 저장됩니다. 팀 공유가 필요하면 Supabase로 옮깁니다.
- 아이콘은 Iconify 서버에서 받아 옵니다(인터넷 필요).
- 3차: 맞히기 화면(S-04), 사용자별 학습 리포트.

폴더 구조: `src/lib`(자모 분해, 통신, 상태, 통계), `src/components`(카드·그래프·손 카드·사이드바), `src/pages`(화면 6개).
