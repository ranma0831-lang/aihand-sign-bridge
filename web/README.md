# Sign Bridge 웹 화면 (역할 4)

표현 모드, 학습 모드, 맞히기, 대시보드 화면입니다. 지금은 **가짜 데이터**로 동작하고, 역할 1(중앙 PC)과 역할 3(인식 AI)이 아래 형식으로 메시지를 보내면 그대로 진짜 데이터로 바뀝니다.

## 실행

```bash
cd web
python -m http.server 8000
```

크롬에서 http://localhost:8000 을 엽니다.
- 음성 입력은 크롬에서만 되고 인터넷이 필요합니다.
- 카메라와 마이크는 `localhost`나 `https`에서만 권한을 받을 수 있습니다.

진짜 PC 서버에 연결할 때는 `http://localhost:8000/?ws=ws://PC주소:8765` 처럼 엽니다. 오른쪽 위 표시가 `가짜 데이터`에서 `PC 연결됨`으로 바뀝니다.

## 화면과 요구사항

| 화면 | 요구사항 |
|---|---|
| 표현: 단어 입력, 음성 입력, 자모 순서, 지금 동작 중인 손 | F-01, F-02, F-09 |
| 학습: 글자 고르기 → 시범 → 웹캠 → 정답/오답 | F-05, F-06, F-07 |
| 맞히기: AI Hand가 보여 준 단어를 보기 4개 중에서 고르기 | S-04 |
| 대시보드: 손 4대 상태, 평균 표현 시간, 학습 정답률, 기록 | F-08, S-05 |

## 메시지 형식 (WebSocket, JSON)

### 화면 → PC (역할 1)
| 메시지 | 언제 |
|---|---|
| `{"type":"express","word":"사랑","seq":["ㅅ","ㅏ","ㄹ","ㅏ","ㅇ"]}` | 표현 모드, 맞히기 문제 |
| `{"type":"demo","jamo":"ㄱ"}` | 학습 모드 시범 |
| `{"type":"recognize","jamo":"ㄱ"}` | 시범이 끝나고 사용자 손 인식 시작 |
| `{"type":"cancel"}` | 진행 중인 동작 취소 |

### PC → 화면
| 메시지 | 뜻 |
|---|---|
| `{"type":"step","i":0,"jamo":"ㅅ","hand":1,"state":"start"}` | i번째 자모 동작 시작 (`hand:null`이면 손 대신 화면 그림) |
| `{"type":"step","i":0,"jamo":"ㅅ","hand":1,"state":"end"}` | i번째 자모 동작 끝 |
| `{"type":"done","ms":6800}` | 단어(또는 시범) 전체 끝, 걸린 시간 |
| `{"type":"error","hand":2,"msg":"연결 끊김"}` | 손 오류 |

### 인식 AI (역할 3) → 화면
| 메시지 | 뜻 |
|---|---|
| `{"type":"recog","jamo":"ㄱ","prob":0.92,"ms":420}` | 인식한 글자, 확신도, 반응 시간(N-03) |

인식 결과도 PC 서버를 거쳐 같은 WebSocket으로 보내면 됩니다.
